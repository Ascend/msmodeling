# MindStudio-Modeling AI Native 开发

本目录帮助开发者用 AI 参与 Issue、开发、PR 检视和 CI 闭环。

从这里开始：

1. AI 客户端先读取 [AGENTS.md](../../AGENTS.md)；
2. 强制规则见 [spec/README.md](../../spec/README.md)；
3. 操作方法见 [工作流指南](workflow-guide.md)；
4. 可直接复制的业务示例见 [使用案例](use-cases.md)；
5. 架构概览见 [架构说明](architecture.md)。

canonical repository 是 `Ascend/msmodeling`。开发分支可 push 到个人 Fork 或主仓分支；正式 Issue、PR、
评论、评审和 CI 面向 canonical repository，并由 `gitcode` CLI 操作。openLiBing 日志由
`gitcode-pipeline-analyzer` 分析。
