# 界面使用指南

msmodeling 建模仿真控制台提供基于浏览器的图形化操作界面，使用户无需记忆命令行参数即可完成仿真任务的配置、运行与结果分析。

控制台支持以下三类仿真场景：

| 场景 | 功能说明 |
| --- | --- |
| 文本生成 | 面向大语言模型的推理性能仿真，输出吞吐、显存占用、算子耗时分布等指标 |
| 视频生成 | 面向扩散模型的视频生成仿真，输出推理执行时间与算子耗时分布 |
| 吞吐优化 | 面向服务化部署的吞吐寻优，在响应延迟达标的前提下求解最优并行、批大小与并发配置 |

本指南按实际操作流程组织，依次说明各页面的功能与使用方式。

---

## 一、界面总览

页面顶部为全局导航栏：

- **左侧**：产品标识。
- **右侧**依次提供：
  - **主页**：进入主工作台。
  - **使用文档**：查看内置说明文档（即本页面）。
  - **历史记录**：查看历史任务列表。
  - **语言切换**：在中文与英文之间切换，页面所有文案（含图表标注）随之同步更新。
  - **主题切换**：在浅色与深色主题之间切换，图表配色随之联动。

控制台共包含四个功能页面：**主工作台**（任务配置与运行）、**历史记录**、**任务详情**（任务进度与结果查看）、**使用文档**。

---

## 二、主工作台

主工作台为日常操作的核心页面，用于完成"配置参数 → 运行任务 → 查看结果"的完整流程。

### 2.1 场景切换

页面顶部以标签页形式提供三个仿真场景（文本生成、视频生成、吞吐优化），点击即可切换。各场景独立保存各自的配置与结果，切换不会丢失数据。

为避免运行状态被意外中断，当某一场景下存在正在执行的任务时，切换标签页将被拦截，并提示用户先等待任务完成或主动取消。

### 2.2 页面布局

每个场景的页面分为上下两个区域：

- **上方**：参数配置表单。
- **下方**：结果展示区域。
- 中间设有**可调节分隔条**，用于调整上下区域的显示比例，支持鼠标拖拽，亦可在选中分隔条后通过键盘操作：`↑` / `↓` 按 5% 步进微调，`Home` / `End` 直接调整至极值。调整范围限定在 20%–75% 之间。

### 2.3 参数配置

表单参数按功能分组，以可折叠卡片的形式组织：

- 点击分组标题可展开或折叠该组，便于按需查看常用参数与高级参数。
- 分组标题右侧显示校验错误数量徽标，折叠状态下亦可直观掌握该组是否存在未通过的校验项。
- 各参数项若带有问号图标，将鼠标悬停其上可查看该参数的说明信息。

表单支持以下输入方式：

| 控件类型 | 适用场景 |
| --- | --- |
| 文本输入框 | 字符串型参数 |
| 数字输入框 | 数值型参数，支持上下限与步进 |
| 下拉单选 | 在给定选项中选择一项（如芯片型号） |
| 下拉多选 | 在给定选项中选择多项，支持检索与一键清空 |
| 开关 | 布尔型参数的启用 / 禁用 |

参数之间具备联动关系：部分参数的显示、可用状态或是否必填，会根据其他参数的取值自动调整。无需关心联动逻辑，按界面实际呈现填写即可，被置灰的项即表示当前无需配置。

部分参数（如芯片型号、量化方式等）支持多选。选中多个取值时，系统将自动为每个取值分别执行一次仿真，并在结果区域提供对比视图，适用于多方案择优的场景。

### 2.4 参数校验

- 参数项在失去焦点或取值变更时触发实时校验，支持必填、取值范围、长度、正则及枚举等规则，错误信息显示于对应输入框下方。
- 点击"运行"时，系统对所有可见且处于可用状态的参数执行整体校验。若存在未通过的校验项，将弹出提示并自动定位至首个出错位置，同时展开其所在分组，便于逐项修正。
- 部分参数间存在跨字段约束（如互斥关系、依赖关系等），将在提交时统一校验。

### 2.5 运行、状态与取消

- 参数配置完成并通过校验后，点击表单右上角的"运行"按钮提交任务。
- 任务提交后进入轮询状态，结果区域显示当前任务状态（等待中 / 运行中）及阶段性的文字说明。受限于仿真任务的特点，**执行期间不提供精确的进度百分比**，状态会持续保持"运行中"直至任务完成。如需了解执行过程的实时细节，请通过"日志"按钮查看运行输出。
- 每个场景同一时刻仅允许执行一个任务，运行期间按钮处于加载状态以防止重复提交。
- 如需中断任务，点击"取消"按钮并确认即可。
- 点击"日志"按钮可打开侧边日志抽屉，查看完整的运行输出。日志支持按子任务筛选、关键字检索及整份复制；当日志持续增长且已滚动至底部时，将自动跟随更新。

### 2.6 结果区域状态

结果区域依据任务当前状态呈现不同内容：

| 任务状态 | 呈现内容 |
| --- | --- |
| 未提交 | 占位提示，引导用户填写表单并提交 |
| 等待中 / 运行中 | 任务状态标识与阶段性文字说明（不提供精确进度百分比，如需细节请查看日志） |
| 成功 | 完成标记、任务编号，以及与所选场景对应的结果组件（图表、表格、下载入口） |
| 失败 | 错误提示，可展开查看错误详情及运行日志 |
| 已取消 / 中断 | 相应状态提示 |

## 三、结果解读

任务执行成功后，结果区域将依据所选场景自动加载对应的结果组件。各场景的结果含义如下。

### 3.1 文本生成

**汇总指标卡片：**

- **每秒 Token 数（TPS）**：表征模型的推理吞吐，数值越高表示单位时间产出越多。
- **执行时间**：完成一次推理的估算耗时。
- **峰值内存 / 设备总内存**：显存占用与设备显存总量，用于评估容量是否充裕。

**图表：**

- **TPS 柱状图**：以模型为单位对比吞吐，柱体越高表示吞吐越高。
- **内存分布饼图**：展示显存被模型权重、KV 缓存、激活值等各部分所占的比例，占比最大的部分即为显存优化的重点方向。
- **算子耗时环形图**：按总耗时排序展示主要算子的占比，耗时最高的若干算子即为性能瓶颈所在。

**表格：**

- **算子耗时明细表**：逐项列出各算子的总耗时、平均耗时及调用次数，默认按总耗时降序排列，排位靠前的算子为性能优化的重点对象。该表支持导出为 CSV 文件，便于离线分析。

### 3.2 视频生成

- **执行时间**：完成一次推理的估算耗时，按性能模型分别给出。
- **算子耗时明细表与环形图**：与文本生成一致，展示各算子的耗时分布，明细表支持导出 CSV。
- **统计卡片**：展示算子种类数、模型细分数等规模信息。

### 3.3 吞吐优化

该场景用于在服务化部署中求解最优配置，结果将依据所选部署方式（聚合、分离部署、PD 配比）自动呈现对应的视图：

- **最优配置卡片**：在醒目位置直接给出推荐配置，包括并行度、批大小、并发数及对应的吞吐指标。
- **配置对照表**：将所有已评估的配置按综合表现排序，列出各项指标的取值，包括吞吐、首字延迟（TTFT）、每字延迟（TPOT）等。在延迟满足约束的前提下，吞吐越高表示配置越优。
- 所有表格均支持导出为 CSV 文件，便于进一步对比与归档。

### 3.4 多配置对比

当配置中存在多选取值的参数时，结果区域进入对比模式：

- **汇总表**：每个配置独占一行，列出关键指标。点击任意一行，可在下方展开该配置的完整结果详情。
- **对比图表与对比表**：将多个配置的同一指标并列展示，便于横向比较，直观呈现各方案的优劣。

### 3.5 性能追踪文件下载

部分场景在任务完成后提供 Chrome Trace 文件下载。

## 四、任务详情页

任务详情页用于查看单个任务的执行状态、复现命令及运行日志，通常由历史记录或运行入口跳转进入。

### 4.1 状态查看

- 页面自动定时刷新任务状态，进入终态（成功、失败、取消、中断）或任务不存在时停止刷新，无需手动操作。
- 任务状态以颜色与图标标识：等待中（灰色）、运行中（蓝色，图标旋转）、成功（绿色）、失败（红色）、已取消（橙色）、中断（红色）。
- 与主工作台一致，任务执行期间**不提供精确的进度百分比**，状态将持续显示为"运行中"直至完成。如需了解执行过程的实时细节，请通过日志查看。
- 任务处于等待或运行状态时，可点击"取消作业"按钮中断执行；任务成功后，可点击"查看结果"按钮跳转至结果页面。
- 当用户在页面内持续观察直至任务成功时，页面将启动约 3 秒的倒计时并自动跳转至结果页，亦可点击"留在此页"中止跳转。

### 4.2 命令与参数

- 页面展示与本次任务等价的**命令行指令**，便于在终端环境中复现或共享。点击"复制"按钮可将其复制至剪贴板。
- 下方可展开查看本次任务的完整参数（JSON 格式），即所填写的全部配置项。

### 4.3 日志查看

点击"查看日志"可打开侧边抽屉，查看本次任务的运行输出快照。如需查看实时滚动的运行日志，建议在主工作台中通过"日志"按钮获取。

---

## 五、历史记录页

历史记录页用于浏览与管理已执行的任务。

- **任务列表**：以表格形式展示历史任务，包含任务编号、场景、标签、状态（彩色标识）、创建时间与完成时间，默认按创建时间倒序排列。
- **筛选**：支持按场景（文本生成 / 视频生成 / 吞吐优化）与状态（等待中、运行中、成功、失败、已取消、中断）进行筛选。
- **检索**：支持按任务编号或标签进行模糊匹配。
- **排序与分页**：支持点击列标题排序；分页支持每页 10、20、50、100 条。
- **任务跳转**：操作列依据任务状态提供对应入口——成功任务可查看结果，运行中任务可查看状态，失败、取消或中断任务可查看详情。

---

## 六、使用文档页

使用文档页用于浏览内置说明文档。左侧为文档列表，点击即可在右侧加载对应内容；左侧下方同时提供当前文档的章节目录，点击目录项可快速定位至对应章节。

## 附：常用操作速查

| 操作目的 | 操作方式 |
| --- | --- |
| 切换仿真场景 | 点击主工作台顶部的场景标签 |
| 调整表单与结果区域的显示比例 | 拖动中间分隔条 |
| 查看参数说明 | 鼠标悬停于参数名称后的问号图标 |
| 对比多个配置方案 | 在支持多选的参数中选取多个取值后运行 |
| 中断运行中的任务 | 点击结果区域的"取消"按钮 |
| 查看运行过程的详细输出 | 点击"日志"按钮打开抽屉 |
| 分析算子性能瓶颈 | 查看结果中的"算子耗时明细表"，排位靠前者为重点 |
| 导出结果数据 | 点击表格的"导出 CSV"按钮 |
| 查找历史任务 | 进入顶部"历史记录"页面，使用筛选或检索 |
| 切换界面语言与主题 | 使用右上角的切换器 |
